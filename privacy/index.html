隐私政策

更新日期：2026-10-28

SEISAMUSE（www.seis-jun.xyz）是 hashes 的个人博客。这份说明介绍访问本站、发表评论或联系作者时，可能涉及的信息处理与第三方服务。

浏览与基础服务

阅读本站无需注册本站账户。网站通过 GitHub Pages 托管；域名、网络分发及部分图片服务使用 Cloudflare。访问网页、图片或脚本时，相应服务提供方可能处理 IP 地址、请求网址、浏览器信息、访问时间等，以传输内容、维护服务和处理安全问题。

相关说明：GitHub 隐私声明、Cloudflare 隐私政策。

访问统计与浏览器存储

本站使用 Umami 了解访问量、来源和页面访问情况；页面上的浏览量和访客数由本站独立的 Cloudflare Worker 与 D1 数据库提供，不再依赖原第三方计数服务。加载这些服务会向相应服务器发送请求，服务提供方的数据处理也受其政策与实际配置约束。

独立计数脚本仅向 stats.seis-jun.xyz 发送当前页面路径、单次浏览的随机事件编号，以及可用时的随机浏览器编号。路径不含查询参数或页内锚点；脚本不读取其他 Cookie、登录凭据或浏览记录。本站计数数据库不保存 IP 地址、User-Agent 或浏览器编号原文，但 Cloudflare 在网络传输和安全防护过程中仍可能处理网络信息。

随机浏览器编号保存在本地 seisamuse-visitor-v2 项中，从建立起有效 365 天，访问不会延长有效期。服务端仅保存其 SHA-256 摘要，用于识别同一编号。清除网站数据、编号过期、更换浏览器或设备，都可能被重新计为访客。浏览器不允许本地存储时仍可记录浏览量，但不因此把每次访问都当成新访客。

历史浏览量 80,500 和历史访客数 40,500 是作者根据此前记录回忆后确认的手动估算，并非原服务的完整导出。页面会用约数标记显示历史基数加新增统计；历史访客与新浏览器编号之间无法去重，因此访客数不等于精确人数。无法确认的单篇历史浏览量不填为零，只显示切换后记录的浏览量。自动访问和拦截统计请求等情况也会影响结果。

数据库保留随机事件编号、页面路径、访问时间及浏览器编号摘要，用于计数和避免重复写入，目前没有自动清理期限，必要的备份也可能包含这些记录。浏览器还会以 seisamuse-counter-site-v2 和 seisamuse-counter-page-v2: 为前缀保存最近一次成功获取的统计汇总，接口暂时不可用时可显示带缓存时间的旧值。你可以清除网站数据移除本地编号、缓存和偏好；这不会同时删除服务器上的记录。本地预览页面仅查询汇总，不写入访问记录。

明暗主题偏好保存在浏览器本地的 seisamuse-theme 项中，供下次访问时使用。你可以通过浏览器的网站数据设置清除它。

评论与主动联系

部分页面使用 giscus 评论系统，评论托管在 GitHub Discussions。发表评论涉及 GitHub 登录及授权，用户名、头像和评论内容可能公开展示。请不要在评论中留下密码、住址、证件号码或其他不希望公开的信息。评论的管理也受 GitHub 的规则约束。

通过邮件联系作者时，作者会收到你主动提供的邮箱地址和邮件内容，用于沟通、处理反馈及保留必要的往来记录。涉及具体邮件或评论的信息请求，可通过文末邮箱联系；第三方账户中的数据可能需要向相应平台申请处理。

外部资源与链接

部分文章使用外部图片、视频嵌入，以及字体、公式和图表脚本；页脚也包含博客目录链接。相关资源可能来自 Unsplash、哔哩哔哩、CDN 或其他文章中注明的服务。加载外部资源时，浏览器可能向其提供方发送 IP 地址、浏览器信息及来源页面信息；打开外部链接后，适用目标网站的隐私规则。

你可以使用浏览器提供的 Cookie、网站数据和内容加载设置管理这些请求，但部分功能可能因此不可用。

保存、更新与联系

公开评论通常在其被删除前保持可见；第三方服务的数据保存期限由其政策及配置决定。对于作者直接收到的信息，可以来信请求查询、更正或删除，作者会根据实际持有的信息和适用要求处理。本站无法代替第三方承诺删除其独立保存的数据。

本站使用的服务变化时，会相应更新本页日期和内容。有关隐私的问题，请联系：hashes@yeah.net。
