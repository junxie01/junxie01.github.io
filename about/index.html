生活理念

人生是游戏 : 人生是游戏，生活是游戏，工作是游戏，所有都是游戏。不必太严肃，也不必太轻浮。认真玩，但别太认真。

人生是体验 : 人生就是一次体验和感受，单程票。来时呱呱坠地一声惊呼，走时两手空空万般皆寂。酸甜苦辣、喜怒哀乐，每一种感受都不可或缺。但你要知道自己在体验，你是载体，不是傀儡。任何一种情绪如果控制了你，都会步入深渊。

凡事皆有利于我 : 一切事情发生皆有利于我。顺境是馈赠，逆境是教训，没有白经历的弯路。关键是你得主动去问：这件事在教我什么？

知行知行，行知行之 : 道听途说的道理不是你的认知，就像学了牛顿定律不代表会做题。穷尽一生也看不透这世界，所以放弃对”终极认知”的执念。想一想再做，做了又思考一下，不要太关注结果，一做了之。

保持肠衣状态 : 学进去的东西如果不经过思索、分解、消化和使用，最终只是一些废气。真正的成长，是用力去解构它，让它真正长在你身上。不自以为是很难，但要努力不自以为是。

与熵增对着干 : 宇宙大部分时候要的是混沌，吃的是熵。你要的是有序——身体有序：好好睡觉，好好吃饭，偶尔锻炼；脑子有序：读书，交流，见识，做事，整合。拥有800亿神经元和意识，就不能像虫豸一样只受基因摆布。

造点有意思的东西 : 人不能只消费，还得创造。不一定是惊天动地的大事，但得是有点意思的东西——一篇文字、一个工具、一段代码、一个脑洞。跟 Paul Graham 说的 “[Make good new things]（https://www.paulgraham.com/do.html）” 是一个意思。

直面而非逃避 : 快乐本身不会成瘾，成瘾是因为逃避——逃避困难、压力、羞愧。短暂快乐背后往往藏着更大的问题。把困难视为学习、成长、提升的邀请，直面生活的挑战。

执着是姿态，结果交给世界 : 阿甘靠的不是运气，而是一颗执着的心。但不是所有执着都有结果，执着是内在的姿态，不是对回报的许诺。

警惕标签，理解立场 : 贴标签是大脑省能量的本能，但也是偏见的温床。”坏”基于立场，换个立场好坏就反转。天地不仁，没有分别心。人受DNA控制又有脑子，成不了佛也成不了圣，人间既是地狱也是天堂。

爱写写写写 : 不发宏愿，只是记录。有些念头不立刻记下来就会溜走，写的时候不得不整理自己，做过的东西记不得跟没做过没差。
