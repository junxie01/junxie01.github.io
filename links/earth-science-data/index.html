地学数据导航

研究里用到的数据入口越来越多，先放在这里，方便下次直接找。优先收录数据生产机构、官方数据中心及论文指定仓库，同时写清楚能拿到什么。

入口核验日期：2026-10-11。 本页收集网址，不托管数据。核验包括机构说明、产品元数据和入口；没有登录下载或检查特定研究区的文件。部分交互网站需要浏览器执行 JavaScript，下载条件和具体版本以官方页面为准。两处未成功打开的数据仓库已单独标注。

SWOT：河流、湖泊与海洋

SWOT 不只是一种数据。 水文侧有水体像元云（PIXC）、栅格（Raster）、河流（RiverSP）和湖泊（LakeSP）产品；海洋侧主要使用 LR SSH。先按用途选产品，再按区域、日期及处理版本检索。

  • NASA PO.DAAC SWOT 产品总入口
    查产品列表、使用指南、质量说明和下载方式。说明页公开，数据下载使用免费 NASA Earthdata 账号；部分说明正在向 Earthdata 网站迁移。
  • SWOT RiverSP：河流产品，Version D
    河段和节点尺度的水位、宽度、坡度、面积及流量估计，Shapefile 格式。面向预定义河网，实际覆盖需按研究区和日期查询。流量是估计产品，不能当作水文站直接观测；使用前看质量标志。下载需 Earthdata 账号。
  • SWOT LakeSP：湖泊产品，Version D
    湖泊及未分类水体的水面高程、面积和质量信息，Shapefile 格式。包含观测湖泊、先验湖泊及未匹配水体；是否观测到目标湖泊需检查覆盖与质量标志。下载需 Earthdata 账号。
  • SWOT KaRIn LR SSH：海洋产品，Version D
    海面高度、海面高度异常、风速和有效波高，NetCDF 格式。Basic / Expert / Windwave 使用 2 km 网格，Unsmoothed 使用 250 m 原生网格；产品校正与水文侧不同。下载需 Earthdata 账号。

上面的 Version D 是本次核验的具体产品入口，不保证始终为最新版本；后续新版本可从总入口查找。

GPS / GNSS：原始观测与位置时间序列

要自行解算位置或大气参数，找 RINEX 观测文件；要研究形变、速度或同震位移，可以先找已解算的位置时间序列。它们不能混为同一种数据。

  • IGS 全球站网地图
    先查研究区附近的站点、接收机、天线、站点日志、卫星系统和关联数据中心。站网页面公开，实际观测文件的下载条件由数据中心决定。
  • NASA CDDIS：GNSS 观测目录
    IGS / MGEX 的 RINEX 观测入口，包含日文件、小时文件和部分站点的高采样率文件。下载需 Earthdata 账号；官方迁移说明确认观测下载目录保持不变。
  • EarthScope / NGF：GNSS 数据
    连续站与流动观测；分别提供 RINEX、位置时间序列、速度、同震偏移及对流层参数。官方页面区分 Level 1 观测和 Level 2 派生产品。部分服务需免费 EarthScope IdM 账号，见认证说明。
  • Nevada Geodetic Laboratory：NGL Plug and Play
    全球台站位置时间序列与 MIDAS 速度场，含 IGS20 及板块参考框架。页面和文本直链公开。使用前核对参考框架、单位、采样间隔、设备变化和偏移记录。

雷达：SAR / InSAR 与气象雷达

SAR / InSAR 主要用于地表遥感与形变；气象雷达用于降水、风场和强天气。冰体内部与冰底结构使用的冰穿透雷达，放在下一节。

  • ASF Vertex：卫星 SAR 检索
    按区域、日期、轨道及产品类型查 Sentinel-1 等雷达影像，也有已处理产品和按需处理入口。下载及处理使用 Earthdata 账号。官方使用说明可查筛选和下载方法。
  • Copernicus Browser：Sentinel 数据
    检索、预览、下载欧洲 Copernicus 数据。Sentinel-1 的 SLC 保留幅度与相位，适合 InSAR；GRD 适合后向散射与地表监测。下载使用免费 Copernicus 账号。见浏览器说明及Sentinel-1 产品说明。
  • COMET–LiCSAR：已处理 InSAR
    Sentinel-1 干涉图和相干性图，按 frame 查询和下载，重点覆盖阿尔卑斯—喜马拉雅构造带及其他构造、火山研究区。实际以已处理 frame 为准；公开入口不等于全球处处都有成品。另有 CEDA 批量目录。
  • NOAA NEXRAD：美国气象雷达
    地基多普勒气象雷达历史与近实时数据，包含 Level II 观测和 Level III 派生产品，用于降水、风场及强天气研究。数字数据免费；产品页列出检索、地图及云端访问方式。

ASF 与 Copernicus 的交互入口本轮只读取到网页外壳，功能和访问条件依据各自官方说明核验。

冰川厚度、冰床与冰穿透雷达

冰厚请区分 测深观测、观测汇编和模型估计。全域厚度栅格通常包含推定值；一个像元有数值，并不代表那里做过直接雷达测量。

  • BedMachine Greenland：格陵兰冰厚与冰床
    冰厚、冰床、表面高程、海底地形及掩膜，常用网格 150 m。结合测深和质量守恒等方法的综合估计。下载需 Earthdata 账号；实际使用时记录版本及对应 DOI。
  • BedMachine Antarctica：南极冰厚与冰床
    南极冰厚、冰床、表面高程和海底地形，常用网格 500 m。综合测量及推定方法；产品标注的输入资料时间范围不代表连续冰厚监测序列。下载需 Earthdata 账号。
  • Farinotti 等（2019）：全球冰川厚度模型集合
    基于 RGI 6.0 的全球冰川厚度估计，适合区域和全球冰储量研究；不能直接与 RGI 7 的 ID 和边界混用。ETH 仓库记录提供按区域组织的数据，许可为 CC BY-NC-SA 4.0。论文。官方记录已定位，仓库本轮返回 403，下载待手动核验。
  • Millan 等（2022）：全球冰川流速与厚度
    山地冰川表面流速及利用流速等约束估计的厚度。可先在 IGE 官方地图查看；数据 DOI和论文及更正入口用于追溯数据。地图可打开，数据 DOI 本轮未成功打开，下载待手动核验。 使用前看覆盖缺口和误差。
  • GlaThiDa：全球冰厚观测数据库
    汇集实地及遥感冰厚观测，CSV 格式，适合寻找实测厚度和检验模型。公开稳定版本汇编的资料范围为 1935–2018；空间采样不均匀。稳定版 DOI与官方维护库的开发版应分别记录；目录说明公开免费，使用须正确引用。
  • IceBridge MCoRDS L2：冰穿透雷达测深
    格陵兰和南极机载雷达沿航线冰厚、冰面及冰底信息，2009–2019，CSV 格式。属于雷达测深处理产品，不是 SAR 影像或全域连续厚度栅格。下载需 Earthdata 账号。数据 DOI · 用户指南。

冰川与冰盖流速

流速产品需要区别单影像对、某个时期的拼接和时间序列；比较不同产品时同时看时间窗口、质量和速度单位。

  • ITS_LIVE：全球冰川流速
    全球主要陆地冰体，1985 年以来；常用 120 m，提供影像对、月度/年度拼接和时间序列数据立方。流速由光学或 SAR 影像位移反演，常用单位为 m/年。地图工具 · STAC 数据接口。旧 V1 的 NSIDC 下载需 Earthdata Login，新产品有云端入口，具体以所选产品说明为准。
  • MEaSUREs / GrIMP：冰盖流速
    格陵兰 GrIMP 汇总年度、季度、月度及较短周期产品。南极可从 NSIDC-0484查多年份观测拼接，不能把它当成单一年份或逐年序列。南极产品 DOI。NSIDC 下载通常需免费 Earthdata 账号。

Millan 的全球流速与厚度联合产品见上一节。

地下水：Wang 等（2025）指定数据

  • 中国逐月地下水位网格（2005–2022）：数据 DOI
    论文指定的国家青藏高原科学数据中心（TPDC）入口；当前对应数据页面。中国范围，1 km，月尺度，GeoTIFF，来自监测井资料的月平均及 IDW 插值。

这是公开的插值网格，不应写成原始井站记录全部开放。 论文原始资料包含 11,911 个监测点及 4,275,506 条观测记录，但原始资料未公开。1 km 是输出网格间距，不代表每个像元都有实测井。论文说明水位单位为 m，并统一到 1985 国家高程基准；使用时还需核对文件元数据和水位/埋深定义。2018 年前后监测站数量和分布明显变化，跨期分析应考虑观测网络变化。

本轮成功读取论文，核验了数据 DOI 重定向和数据页 HTTP 响应；TPDC 页面为 JavaScript 外壳，尚未核验登录后的文件清单及下载权限。

论文：Wang, M., Yao, J., Chang, H., Liu, R., Xu, N., Liu, Z., Gong, H., Zheng, H., Wang, J., Guo, X., Cao, Y., Zhao, Y., and Lu, H. (2025). Underground well water level observation grid dataset from 2005 to 2022. Scientific Data, 12, 728. 10.1038/s41597-025-04799-y。

气象、降水与陆面驱动

再分析和融合网格不是逐格直接观测；站点资料没有统一网格分辨率。降水率与累积降水量也要分清，尤其是 mm/h、mm、kg m⁻² s⁻¹ 等单位。

  • ERA5：全球单层气象再分析
    1940 年起，逐小时，大气变量下载网格通常为 0.25°；温度、降水、风、气压等。使用 CDS 账号，支持网页与 API。此链接是单层资料，高空气压层需另选产品。
  • ERA5-Land：全球陆面再分析
    1950 年起，逐小时，0.1° 输出网格，原生分辨率约 9 km。可找土壤水分、积雪、径流、蒸发和近地面气象。使用 CDS 账号。
  • NOAA GHCN-Daily：全球站点日值
    最高/最低气温、降水、降雪和雪深等；覆盖时段与变量完整性因站而异。公开 HTTPS 目录可按站点或年份取文件，无需登录。
  • NOAA ISD / Global Hourly：全球站点小时资料
    气温、露点、风、气压、能见度、降水和雪深等。总体记录从 1901 年起，各站覆盖和缺测不同；官方页提供公开目录、检索和 API 入口。
  • NASA GPM IMERG：多卫星融合降水
    V07B，1998 年起，0.1°，有半小时、日和月产品。长期科研分析可先看 Final，近实时用途看 Early / Late。产品目录列出不同分支与下载方式；GES DISC 通常使用 Earthdata 账号，PPS 有独立注册说明。
  • CHIRPS：卫星与站点融合降水
    1981 年起，0.05°，60°S–60°N，适合长期降水和干旱研究。v3 已提供服务；v3.0 公开目录无需登录。与旧 v2 比较时记录版本及所选时间产品。
  • 中国气象数据网
    中国地面、高空、气象卫星及天气雷达资料。常用地面日值 V3.0 元数据列有温度、气压、降水、蒸发、湿度、风、日照及地温，并说明教育科研实名注册访问。本轮官方元数据可从检索结果定位，页面直接读取失败；具体可用范围和权限需登录核对。
  • CMFD v2.0：中国区域气象驱动
    中国及邻近陆地区域，1951 年起，0.1°，3 小时；温度、气压、比湿、风速、短波/长波辐射和降水率等。清华官方发布说明在 2025 年已公布扩展至 2024 年；结束年份以平台当前文件为准。稳定数据 DOI。TPDC 入口本轮只读取到网页外壳，具体下载权限未实测。

辅助数据：地形、冰川边界、流域与储水

  • NASA Earthdata Search：综合数据检索
    按关键词、时间和区域查 NASA 地球科学数据，包括水文、冰冻圈、气象及陆表产品。检索公开，很多数据下载需免费 Earthdata 账号；账号与访问说明。
  • USGS EarthExplorer：影像与高程检索
    按区域和日期检索，再在 Data Sets 中选择数据。适合查 Landsat 等影像及高程产品；下载和订购场景需登录 USGS 账号。
  • OpenTopography：DEM 与点云
    检索全球/区域 DEM 与高分辨率点云，包括 SRTM、NASADEM、Copernicus 等。访问说明区分公开和受限增值服务：部分产品有账号、学术资格、订阅或 API 限制，不能一概写成免费无限下载。
  • ArcticDEM / REMA：极地地表高程
    ArcticDEM 面向北极陆地，REMA 面向南极；光学立体影像生成地表高程，包含 2 m 条带及多分辨率拼接。REMA 产品页 · 官方产品指南 · FRIDGE 地图。公开 DEM 通常无需账号，部分近期阿拉斯加资料有访问限制。高程为 WGS84 椭球高；冰面高程不是冰厚或冰底高程。
  • RGI / GLIMS：全球冰川边界与清单
    RGI 是面向约 2000 年目标时期的全球冰川轮廓快照，排除格陵兰和南极主体冰盖；GLIMS 可查多时相轮廓。RGI 用户指南 · RGI 数据入口 · GLIMS。旧 RGI 地址已迁至 rgidata.org；数据入口由官方项目页提供，NSIDC 下载页本轮未成功读取。
  • HydroSHEDS：流域、河网与湖泊
    HydroBASINS 是流域边界，HydroRIVERS 是河网，HydroLAKES 是湖泊，HydroATLAS 添加水文环境属性。适合配合 SWOT 和流域研究；属于地理基础及派生数据，不是实测流量时间序列。HydroBASINS 下载与许可。
  • GRACE / GRACE-FO：陆地储水变化
    全球月尺度质量变化及等效水厚异常，可从 JPL Mascon CRI 产品进入下载，使用 Earthdata 账号。它包含多种储水成分，不是直接地下水位；JPL 产品的 0.5° 输出采样不等于 0.5° 独立空间分辨率，原生 mascon 约 3°。

来源与后续维护

每项链接同时作为说明来源，优先使用机构产品页和稳定 DOI。涉及论文数据时保留论文入口；网页未成功读取、需要账号或下载未实测的情况已在对应条目说明。网站能打开不代表研究区有数据，也不代表数据质量已经经过本地验证。

以后增补资源时，沿用这个页面：记录名称、官方入口、用途/覆盖、访问条件、版本及核验日期。本站的文章搜索目前只搜索博客；查本页请用上面的分类跳转或浏览器页面内查找。
